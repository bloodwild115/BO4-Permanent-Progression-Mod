# Permanent Progression v1.0.0 — Feature Overview

Permanent Progression is designed as a persistent BO4 Zombies progression layer.

## Permanent Upgrades

Upgrade families use persistent keys and tiered progression. Purchased upgrades can be enabled or disabled where supported.

## Key Economy

The mod uses regular and Sentinel key progression for permanent unlocks and mastery upgrades.

## Loadout Mastery

Standalone v1.0.0 includes PP-owned Armory support so Loadout Mastery does not require BO4 Enhancement.

## Weapon Camos

Performance and Technical camo requirements are rebalanced across the Zombies weapon roster. The Armory displays Permanent Progression requirements and lifetime progress.

## Standalone Release

v1.0.0 intentionally ships without BO4 Enhancement compatibility.

Enhancement-dependent perk upgrade trees are hidden rather than shown as unusable content.
