# Weapon Camo Changes

Permanent Progression v1.0.0 rebalances Zombies weapon camo progression by weapon type and availability.

## Performance challenges

Performance requirements are weapon-specific rather than relying on one universal profile. Some weapons use headshots while others correctly use regular kills based on their weapon behavior.

Examples of special kill-based handling include:

- Welling
- Hitchcock M9
- Escargot
- VKM 750
- Paladin HB50
- shotguns / launchers where appropriate

Special melee/projectile weapons use their own progression profiles.

## Technical challenges

Technical requirements are scaled to match each weapon's revised Performance progression.

Special challenge sets are retained where appropriate, including dedicated melee/special-weapon requirements.

## Armory progress

The Armory displays Permanent Progression requirement text and lifetime progress using persistent weapon statistics wherever supported.

Existing earned camos are not intentionally revoked by v1.0.0.
