# BO4 Permanent Progression Mod

A standalone long-term progression mod for **Call of Duty: Black Ops 4 Zombies** running through **Shield Client**.

Permanent Progression adds a new form of currency, progression upgrades, mastery systems and rewards, enhancements to perks/specialists/AATs/Loadouts, and more, and a rebalanced weapon-camo progression system designed to give BO4 Zombies a longer-term progression loop across matches.

## Current Release

**v1.0.0 — Standalone**

BO4 Enhancement compatibility is **not included in v1.0.0**. An optional compatibility release may be developed in the future.

## Features

- An upgrade system designed to get you hundreds of hours! With content built to be game-system defining and endorse map variety.
- A new Key currency system used for upgrading, earned by lifetime rounds completed on certain maps and match milestones.
- A prestigious currency on top if this called the Sentinel Key, befit for only the most dedicated players for the most game-enhancing rewards. Earned from high round milestones and Main Quest completion for each map.
- Upgrade enable/disable every single upgrade! Play your way with no reprecautions.
- Standalone **PERMANENT UPGRADES** lobby integration.
- Loadout mastery and upgrades to the Armory.
- Weapon-specific camo rebalancing to make the grind still feel earned but a lot less tedious for how brutal it was in vanilla. Will be expanded on in the future!
- Download, Extract, Drag-and-drop Shield Client installation to make the install process as easy as pie.

# A New Perk System

Perks are now going to be expanded on like never before! Bringing variety to each map while still keeping homeage to classic gameplay roots.
- Physical perk machines are now in EVERY MAP! Because of this, im removing the class perk selection and making the 4 core statues/colas traditional set perks that change between maps.
- The new system provides variety but still gives you comfort if you dont like the 4 core perks in the map! You can now buy the 4 core statue perks, as well as 4 *optional* perks around the map in their traditional perk machine fashion. This allows you to earn up to *8* perks in a match. The core perks are optional but have no effect on your 4-perk limit.
- your perk limit *can be expanded upon* by the Permanent Upgrades menu to have up to *8* optional perks ON TOP of the 4 core perks! You still need to make decisions in a map, but its still going to be a major benefit to doing some of the harder challenges to earn Sentinel Keys. In total, you can have up to 12 perks!
- *Modifiers* are different in this a bit! Your Odin perk still provides its modifier upon the core 4 being purchased, but you still can gain an *Additional Modifier* with your optional perks. Your 4th optional perk bought will receive its Modifier effect, still letting you choose that perk boost in-game instead of in-menu. Upon getting the upgrade for 8 optional perks, your 4th AND 8th slots will provide the modifier effect. That means up to 3 modifiers at once!

# Classic Point System
The classic point system returns! Being based on bullets hitting zombies rather than the modern-era where its based on damage to zombies. Be as efficient as your heart desires!

# Health Changes
- Juggernog isnt implemented into this mod so health is reworked slightly so you still feel like you need to earn that extra hp instead of spawning in with it.
- You start at 150HP/3 Hits now upon spawning in. Unlocking Power can increase your health up to 250HP after.
- Some maps will incrementally increase your hp from 150>200>250HP depending on its power process to promote balance.
- NOTE: This system is still being tweaked for some maps so you dont just instantly hit the power switch round 3 and then never have to worry about health again since the sentinel artifact was 2 doorbuys from spawn.

# A new Currency - Keys/Sentinel Keys
Keys are the bread and butter for earning your Permant Upgrades in this mod. You use them for essentially everything!
- Earn Traditional Keys through playing maps. Each map provides a unique key that goes to a different upgrade to promote playing different maps for different upgrades! (ex: Dead of the Night provides Danu Keys, whereas Alpha Omega provides Broken Arrow keys).
Ways to earn keys include:
- Every 20 lifetime rounds on a map = 1 key
- Round 25 milestone = +1 key rewarded
- Round 50 milestone = +2 keys rewarded
- Round 75 milestone = +3 keys rewarded
- Round 100 milestone = +1 *Sentinel* key rewarded.
- Completion of the map Main Quest = +1 *Sentinel* key rewarded.
- You can also convert 10 normal keys into its Sentinel version if you dont want to deal with the grind of main quests or reaching extreme high rounds! Just check the bottom of the *SENTINEL UPGRADES* tab to see them all.

## Installation

1. Install and configure **Shield Client** for Black Ops 4.
2. Download `PermanentProgression-v1.0.0.zip` from this repository's Releases page.
3. Close Black Ops 4 completely.
4. Extract the ZIP.
5. Copy the included `PermanentProgression` folder into:

   ```text
   C:\Call of Duty Black Ops 4\project-bo4\mods\
   ```

6. The final path should look like:

   ```text
   C:\Call of Duty Black Ops 4\project-bo4\mods\PermanentProgression\
   ```

7. Launch Black Ops 4 through Shield Client.
8. Open Zombies and confirm **PERMANENT UPGRADES** appears in the lobby.

See [Installation & Troubleshooting](docs/INSTALLATION.md) for more detail.

## Weapon Camo Progression

Permanent Progression v1.0.0 includes weapon-specific Performance challenge balancing and scaled Technical challenge requirements. Armory requirement text and progress use lifetime weapon statistics wherever supported.

- No more are you stuck getting 2400 headshots with the Welling! It now just requires kills, so get to packing and enjoy the explosives just a bit more! 
- Some weapon challenges were tuned/altered/reduced to prevent slowing down traditonal gameplay for tediousness of a camo (bowie knife challenges especially)
- box and wall weapons requirements are unique per class/weapon to promote a more fluid grind.

See [Weapon Camo Changes](docs/WEAPON_CAMOS.md).
